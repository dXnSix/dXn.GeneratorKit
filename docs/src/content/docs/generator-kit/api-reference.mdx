# API Reference

This page provides comprehensive documentation for all public APIs in Six.GeneratorKit.

## Collections

### EquatableArray&lt;T&gt;

An immutable, equatable array that provides value equality support for incremental source generation scenarios.

```csharp
public readonly struct EquatableArray<T> : IEquatable<EquatableArray<T>>, IEnumerable<T>
    where T : IEquatable<T>
```

#### Properties

| Property | Type | Description |
|----------|------|-------------|
| `IsEmpty` | `bool` | Gets a value indicating whether the current array is empty |
| `this[int index]` | `ref readonly T` | Gets a reference to an item at a specified position |

#### Static Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `FromImmutableArray(ImmutableArray<T>)` | `EquatableArray<T>` | Creates an instance from an `ImmutableArray<T>` |

#### Instance Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `Equals(EquatableArray<T>)` | `bool` | Determines if two arrays are equal by value |
| `GetHashCode()` | `int` | Gets a hash code based on the array contents |
| `AsImmutableArray()` | `ImmutableArray<T>` | Returns the underlying immutable array |
| `AsSpan()` | `ReadOnlySpan<T>` | Returns a read-only span of the array contents |
| `ToArray()` | `T[]` | Copies contents to a mutable array |
| `GetEnumerator()` | `ImmutableArray<T>.Enumerator` | Gets an enumerator for the array |

#### Operators

| Operator | Description |
|----------|-------------|
| `implicit operator EquatableArray<T>(ImmutableArray<T>)` | Converts from `ImmutableArray<T>` |
| `implicit operator ImmutableArray<T>(EquatableArray<T>)` | Converts to `ImmutableArray<T>` |
| `==`, `!=` | Equality and inequality operators |

#### Example

```csharp
// Create from ImmutableArray
var immutableArray = ImmutableArray.Create("a", "b", "c");
EquatableArray<string> equatableArray = immutableArray;

// Value equality works for incremental generation
var other = EquatableArray<string>.FromImmutableArray(immutableArray);
bool areEqual = equatableArray == other; // true

// Use in data models
public record GeneratorData(EquatableArray<string> Items);
```

### ImmutableArrayBuilder&lt;T&gt;

A high-performance builder for creating immutable arrays using pooled buffers.

```csharp
public ref struct ImmutableArrayBuilder<T>
```

#### Properties

| Property | Type | Description |
|----------|------|-------------|
| `WrittenSpan` | `ReadOnlySpan<T>` | Gets the data written so far as a span |
| `Count` | `int` | Gets the number of items added |

#### Static Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `Rent()` | `ImmutableArrayBuilder<T>` | Creates a new builder with a pooled buffer |

#### Instance Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `Add(T)` | `void` | Adds an item to the builder |
| `AddRange(ReadOnlySpan<T>)` | `void` | Adds multiple items |
| `ToImmutable()` | `ImmutableArray<T>` | Creates an immutable array |
| `ToArray()` | `T[]` | Creates a mutable array |
| `AsEnumerable()` | `IEnumerable<T>` | Gets an enumerable view |
| `Dispose()` | `void` | Returns the pooled buffer |

#### Example

```csharp
using var builder = ImmutableArrayBuilder<string>.Rent();

builder.Add("first");
builder.Add("second");
builder.AddRange(new[] { "third", "fourth" });

var result = builder.ToImmutable();
// builder.Dispose() called automatically with 'using'
```

## Extensions

### AttributeDataExtensions

Extensions for working with `AttributeData` objects.

#### Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `GetLocation()` | `Location?` | Gets the location of the attribute |
| `HasNamedArgument(string)` | `bool` | Checks if a named argument exists |
| `HasNamedArgumentWithValue<T>(string, T?)` | `bool` | Checks if named argument has specific value |
| `GetNamedArgument(string, string)` | `string` | Gets named argument as string with fallback |
| `GetNamedArgument<T>(string, T?)` | `T?` | Gets typed named argument with fallback |
| `TryGetNamedArgument<T>(string, out T?)` | `bool` | Tries to get named argument |
| `GetConstructorArguments<T>()` | `IEnumerable<T?>` | Gets all constructor arguments of type T |
| `HasConstructorArguments()` | `bool` | Checks if constructor arguments exist |
| `GetConstructorArgument(int, string)` | `string` | Gets constructor argument as string |
| `GetConstructorArgument<T>(int, T?)` | `T?` | Gets typed constructor argument |

#### Example

```csharp
// Attribute: [MyAttribute("test", Value = 42)]
var nameArg = attributeData.GetConstructorArgument(0, ""); // "test"
var valueArg = attributeData.GetNamedArgument<int>("Value", 0); // 42
bool hasValue = attributeData.HasNamedArgument("Value"); // true
var location = attributeData.GetLocation(); // Source location
```

## Services

### GeneratorService

A centralized service for handling errors and diagnostics in source generators.

#### Static Methods

| Method | Return Type | Description |
|--------|-------------|-------------|
| `Add(DiagnosticDescriptor, Location?)` | `void` | Adds a diagnostic error |
| `Clear()` | `void` | Clears all collected errors |
| `Report<TValue>()` | `GeneratorResult<TValue>` | Reports errors as GeneratorResult |
| `Report<TValue>(TValue, DiagnosticDescriptor, Location?)` | `GeneratorResult<TValue>` | Reports with value and additional error |

#### Example

```csharp
try
{
    // Generator logic
    var result = GenerateCode();
    return GeneratorService.Report(result);
}
catch (Exception ex)
{
    GeneratorService.Add(MyDiagnostics.GenerationError, location);
    return GeneratorService.Report<string>();
}
```

## Compatibility

### ExternalInit

Provides compatibility for `init` accessors on older target frameworks.

```csharp
#if NETSTANDARD2_0 || NETCOREAPP3_1
public static class IsExternalInit { }
#endif
```

This enables the use of `init` accessors in records and properties when targeting .NET Standard 2.0.

## Best Practices

### 1. **Use Equatable Collections**
Always use `EquatableArray<T>` in your data models to ensure proper incremental generation behavior.

### 2. **Dispose Builders**
Use `using` statements with `ImmutableArrayBuilder<T>` to ensure proper cleanup.

### 3. **Handle Errors Consistently**
Use `GeneratorService` for centralized error handling and reporting.

### 4. **Leverage Extensions**
Use the rich extension methods to simplify common operations.

### 5. **Check for Nullability**
Many extension methods return nullable types - always check for null values.

## Performance Notes

- `EquatableArray<T>` uses value equality which is essential for incremental generators
- `ImmutableArrayBuilder<T>` uses pooled buffers for optimal memory usage
- Extension methods are optimized for common scenarios
- All collections implement proper equality and hashing for incremental scenarios
